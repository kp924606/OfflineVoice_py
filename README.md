# OfflineVoice
OfflineVoice/離線語音

## 1. pyttsx3 是一個 Python 套件，用來實現文字轉語音（TTS，Text-to-Speech）的功能。這個庫允許你將文字轉換為語音，並播放出來，廣泛應用於語音助手、語音提示系統以及其他需要語音輸出的應用中。

```diff
! 使用時不需要連線網際網路
```

主要功能：

●可以在多個平台上運行，包括 Windows、macOS 和 Linux。

●與其他 TTS 庫（例如 Google 的 TTS 或 Amazon Polly）不同，因為它是本地安裝的，不需要依賴外部的 API。

●支持多種語音設置：

  - 語速（rate）：你可以調整語音的語速，範圍從 50 到 500。
  
  - 音量（volume）：你可以設置語音的音量，範圍從 0（靜音）到 1（最大音量）。
  
  - 語音（voice）：你可以選擇語音的種類，例如不同的語言（中文、英文等）、性別（男性或女性）等。
  
## 2. Install Command：
Please refer the command as below.

```bash
pip install pyttsx3
```
